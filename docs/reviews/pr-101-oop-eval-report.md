## Critical Issues (Severity: High)

1. **Symlinked descendants escape the scope guard and lose their identity (open on `7d627ae` and `dd23741`).** Principle: [Backup Creation](https://github.com/WesleyMFrederick/0-documents/blob/main/markdown-documents/architecture-principles/object-oriented/ARCHITECTURE-PRINCIPLES.md#^backup-creation) and the rename scope contract in [005 · Interfaces](../spec/005-interfaces.md#`jact%20rename%20<source...>%20<destination>`). `planMoves` checks scope only for each top-level source (`:410-414`). `filesUnder` lists a file symlink as an ordinary file (`:309-316`), and `planMoves` adds it to `moved` under its link path (`:486-492`). `planFiles` then parses it through the link (`:558-575`), and `commitPlan` renames the staged text over the link path (`:748-754`). Parent-observed: `scope/notes/secret.md` linked to `root/secret.md` outside scope; `jact rename notes archive --scope scope --fix` exits 0 and creates a regular `archive/secret.md` that holds the external private content with a rewritten link. The external file is unchanged. Fix (about 20 minutes plus one regression test): in the directory branch of `planMoves`, `lstat` each descendant and refuse with `RenameValidationError` when a symlink resolves outside `canonicalScope`; also refuse a plan that would edit any symlink path, because the write replaces the link.
2. **Rollback stopped at the first recovery error (published `7d627ae`; resolved in `dd23741`).** Principle: [Backup Creation](https://github.com/WesleyMFrederick/0-documents/blob/main/markdown-documents/architecture-principles/object-oriented/ARCHITECTURE-PRINCIPLES.md#^backup-creation). One `try` wrapped all recovery steps (`:770-787`), so an `rmdirSync` failure skipped edit restoration. Parent-observed fault probe: a failed second move plus a foreign file in `new/dir` gave exit 2 `ENOTEMPTY`; moves were reversed, but `a.md` and `index.md` kept rewritten links. `dd23741` (`rename-markdown-file.ts:768-814`) runs each recovery step in its own `try`, maps restore paths through unreversed moves, and adds a child-process fault regression test.
